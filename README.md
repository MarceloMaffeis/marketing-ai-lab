## 🧠 Suporte a Motores de IA (Local, Google e Microsoft)

A plataforma conta com arquitetura de IA flexível:
1. **⚡ Motor Local Inteligente (Padrão / Sem Chave):** Executa 100% offline via heurísticas locais e RAG embutido, sem custos e sem limite de requisição.
2. **🔷 Google AI Studio (Gemini):** Suporte nativo à API REST do Google Gemini (`gemini-2.5-flash`, `gemini-1.5-flash`).
3. **🟩 Microsoft Foundry / Azure OpenAI (GPT):** Conexão direta com endpoints Microsoft Azure OpenAI / Foundry para modelos GPT (`gpt-4o-mini`, `gpt-4o`).

## 💻 Como Rodar Localmente

1. Clone este repositório:
```bash
git clone https://github.com/seu-usuario/marketing-ai-lab.git
cd marketing-ai-lab
```

2. Instale as dependências:
```bash
pip install -r requirements.txt
```

3. Execute o aplicativo:
```bash
streamlit run app.py
```

4. O sistema abrirá automaticamente no seu navegador em `http://localhost:8501` sem necessidade de login.

## 🤗 Deploy Gratuito no Hugging Face Spaces

1. Crie uma conta gratuita em [huggingface.co](https://huggingface.co/).
2. No menu superior direito, clique em **"New Space"**.
3. Preencha as configurações:
   * **Space name:** `marketing-ai-lab`
   * **License:** `mit`
   * **Select the Space SDK:** Escolha **Streamlit**
   * **Space hardware:** **CPU basic • 2 vCPU • 16GB (Free)**
   * **Privacy:** **Public**
4. Conecte seu repositório do GitHub ou faça o upload dos arquivos.
5. Pronto! Seu laboratório estará online em minutos.

## ☁️ Deploy no Streamlit Cloud

1. Suba esta pasta para um repositório no seu **GitHub**.
2. Acesse [share.streamlit.io](https://share.streamlit.io) e faça login com sua conta do GitHub.
3. Clique em **"New App"** e selecione o seu repositório.
4. Defina o **Main file path:** `app.py`.
5. Clique em **"Deploy!"**.
